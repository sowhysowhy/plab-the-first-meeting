# P.lab 活動企劃社｜第一次社員大會

2026 年 11 月 24 日 · 18:30–20:00

單頁靜態網站，供現場主持投影與社員手機瀏覽。使用 HTML、CSS 和原生 JavaScript，無須安裝套件。

## 預覽與使用

可直接在瀏覽器開啟 `index.html`。也可以從專案根目錄啟動本機伺服器，再瀏覽 `http://localhost:8000`。

```sh
python3 -m http.server 8000
```

- 點選「主持模式」，以固定導覽或「上一區／下一區」切換。區塊內容較長時可在同一區塊內捲動。鍵盤的 ←／→ 可切換區塊，Esc 可離開主持模式。
- 破冰倒數可開始、暫停、繼續及重設。選擇不同階段會載入該階段的完整時間並等待開始。切換網站區塊會保留倒數狀態。
- 參與地圖的勾選僅供當下思考。網站不儲存或傳送選擇，也不收集社員資料。

## 輸入活動資料

設定集中在 `config.js`。欄位留空時，頁面會顯示待補、尚待設定或待確認。

| 欄位 | 如何設定 |
| --- | --- |
| `eventPhotos` | 將毛根花手作活動的實際照片放入 `assets/`，為每張照片新增包含 `src`（相對路徑或 HTTPS 圖片網址）及 `alt`（畫面描述）的項目。 |
| `projectVideoUrl` | 填入「捷運臺北車站感官友善計畫」90 秒紀錄影片的公開網址。支援 YouTube、Vimeo、Google Drive 預覽及可直接播放的 MP4／WebM。嵌入影片需開放觀看與嵌入權限。 |
| `participationFormUrl` | 貼上提供給填答者的 Google 表單連結，支援 `forms.gle` 分享連結與 `docs.google.com/forms/…/viewform`。 |
| `christmas.theme`、`christmas.lead`、`christmas.tasks` | 確認後填入聖誕節活動的實際主題、負責人及可參與工作。 |

毛根花手作案例以討論題呈現。若要補入當時的活動構想、宣傳、成本、籌備或執行細節，可編輯 `index.html` 中的案例卡。

## 主要檔案

- `index.html` 包含首頁、會議流程和四個區塊的內容。
- `styles.css` 控制手機、桌面及主持投影的版面。
- `app.js` 處理區塊切換、破冰倒數及以設定載入素材。
- `config.js` 集中管理素材與待確認的活動資訊。
- `vercel.json` 設定從專案根目錄部署靜態檔案。

## 部署至 Vercel

在 Vercel 匯入這個 GitHub 儲存庫，根目錄維持儲存庫根目錄，框架使用 **Other**，即可部署。專案已指定靜態輸出目錄，無須設定建置指令或環境變數。
